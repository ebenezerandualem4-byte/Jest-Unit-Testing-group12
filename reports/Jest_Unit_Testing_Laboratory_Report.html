10.2 Analysis: Condition Combination Not Guaranteed by Branch Coverage Alone

Short-Circuit Evaluation & Condition Masking: In if (isInternational && score < 75), branch coverage requires only that the compound decision evaluates to true and false at least once. However, when isInternational is false, short-circuit evaluation prevents the second operand (score < 75) from being evaluated. A test suite can achieve 100% branch coverage with a domestic applicant having score 70, without ever verifying what happens when isInternational: true and score >= 75. Full combinatorial testing (MC/DC) is required to guarantee that international students with high scores properly bypass review.

13.2 Higher-Order Interactions and Masking

Fault Masking in TOM: Relational mutations (>) make the conditions strictly narrower, whereas the logical mutation (||) makes the condition broader. 14.3 Technical Justification for Equivalent Mutants

  1. Line 13 (Guard Subsumption): typeof amount !== "number" || !Number.isFinite(amount) mutated to false || !Number.isFinite(amount). In JavaScript, Number.isFinite(x) is false for all non-numbers. Replacing the type check with false cannot alter execution on any input.
  2. Line 33 (Exhaustive Branching): else if (method === "bank") mutated to else if (true). Because preceding validation already rejected any method other than "card" or "bank", if method is not "card", it is guaranteed to be "bank". Mutating this guard to true is an equivalent mutant.
  3. Line 41 (Machine Epsilon Invariant): (amount + fee + Number.EPSILON) mutated to - Number.EPSILON. At transaction scales multiplied by 100 ($> 100$), $2.22 × 10^{-16}$ is below the IEEE-754 double precision least significant bit, rendering $+ epsilon$ and $- epsilon$ bit-identical under floating-point arithmetic.
